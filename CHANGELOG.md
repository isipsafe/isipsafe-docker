# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-02

### Added

- Image with the isipsafe CLI 0.1.0 on Python 3.13 Alpine, running as a non-root user.
- `sync-blocklist` mode that keeps a blocklist file up to date on a volume and keeps the previous list when a download fails.
- nginx docker compose example.
